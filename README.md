## Sobre mim

Sou desenvolvedor full stack e graduando em Engenharia de Software, com experiência na criação de aplicações web, APIs REST, plataformas administrativas e soluções orientadas a dados.

No backend, trabalho principalmente com **Python, Django e Django REST Framework**. No frontend, desenvolvo interfaces com **React e TypeScript**, integrando aplicações a APIs e construindo experiências responsivas para ambientes públicos e administrativos.

Atualmente também estou aprofundando meus conhecimentos em **Java 25, Spring Boot, Spring Data JPA, Hibernate e Maven**, ampliando minha atuação no desenvolvimento backend.

Além da tecnologia, atuo como professor de música. Essa experiência fortaleceu minha comunicação, minha didática e minha capacidade de transformar problemas complexos em soluções mais claras.

- Desenvolvimento backend com Python, Django e APIs REST
- Desenvolvimento frontend com React e TypeScript
- Experiência em produtos digitais para gestão pública e projetos culturais
- Interesse em inteligência artificial, análise de dados e automação
- Localização: Monte Carmelo, Minas Gerais, Brasil
